# M7 原创数学教学诊断候选集与双审说明

本批是**40条作者原创、贴近课堂表达的合成候选案例**，不是收集到的真实学生作业或学生对话。题目、原始步骤、后续回答均由项目作者编写；`source.kind=AUTHOR_CREATED`，全部 `reviewStatus=PROVISIONAL`。没有教师参与本批审定，教师审核数为0。`studentReplies` 是供工程回放使用的预设脚本，不表示学生真的说过这些话，也不表示模型已经成功引导学生纠正。

当前冻结候选版本为 `2026-10-23.2`，datasetId 为 `m7-math-author-created-candidates`，canonical datasetHash 为 `241f0a5821f7310d5a8073a48af83af31d8fb9b0369a23875a6e59c35a6b707e`。本次仅完成文件/schema、数学参考值、工程审读与分区校验，**不能进入教师质量正式统计，不能宣称教育准确率、追问有效率或学习效果**。

学段为小学高年级3条、初中28条、高中9条。题面覆盖数与运算、方程/不等式、几何、统计、概率、函数、数列、对数、导数、三角函数、向量等内容。本集没有真实学生年龄或个人信息。`gradeBand` 只是作者对题目适配范围的工程声明，尚未经教师核实。

每条有2条预设学生回答，初始 `turnCount=0`、`messages=[]`、`findings=[]`。回答包括自我纠正、数学解释、学生对先前归因的反驳，以及无法补图、不愿重拍或拒绝补充过程。它们是固定脚本，未按任意实际模型问句作自适应生成；回放结果因此只能在这一受限条件下解读。

`scenarioType` 是作者的分层标签，方法错误与概念错误的界限仍需教师判断。不能把它当作已经证明的学生心理成因。错误传播也不重复计算为多个独立错误，例如百分数首步算错后导致现价错误，只把首个独立错误列入暂定定位。

24/16清单分别位于 `tests/evaluation/m7/debug.case-ids.json`、`blind.case-ids.json`。每条显式带 `familyId`，40个题族在两个分区间无交叉；没有仅替换数字后跨分区放入的配对题。相关知识点可以出现于两侧，但解题结构和诊断目标不同，例如DEBUG的平方方程漏负根与BLIND的根式方程平方后留增根，分别检查解集完整性与原式等价条件。

`BLIND` 目前只是冻结分区标记。作者编题、工程审读和离线校验均接触过这些输入，不能据此声称已经开展真实盲测。尚未对该分区调用模型。后续不得使用BLIND模型输出调提示词后再将同一分区称为未见最终测试集；若确需工程审计，应按会话评测流程标为BLIND_AUDIT并保留审计原因，之后另建立未调优的最终测试集。

## 输入、暂定标注与参考解分离

| 文件（相对仓库根目录） | 内容与用途 |
| --- | --- |
| `tests/evaluation/m7/math-candidates.inputs.json` | 40条严格会话输入；没有expected、参考解、教师目标或评语 |
| `tests/evaluation/m7/math-candidates.annotations.provisional.json` | 独立sidecar中的作者暂定定位、可接受粗类及行为目标；`AUTHOR_PROVISIONAL`、DRAFT、无审核签收 |
| `tests/evaluation/m7/math-checks.provisional.json` | 每例参考解、作者工程审读说明和确定性数值断言；不供模型读取 |
| `tests/evaluation/m7/teacher-reviewer-a.template.json` | 教师A的空白标注模板；字段为null，未预填工程答案 |
| `tests/evaluation/m7/teacher-reviewer-b.template.json` | 教师B的独立空白标注模板；与A同样没有教师标签 |
| `tests/evaluation/m7/debug.case-ids.json` / `blind.case-ids.json` | 两个固定分区的caseId/familyId及datasetHash绑定 |
| `tests/evaluation/m7/hashmanifest.json` | 文件字节hash、完整输入集hash、逐例inputHash、数量及分区绑定 |

会话调用只可将当前案例的 `initialContext` 和依序进入的学生回答传给模型；case上的scenario、tags、family、来源信息与所有sidecar不进入模型上下文。预设学生回答在到达对应回合前不可提前加入模型输入。参考解、教师评语、工程预期同样不得放进prompt。

`trueWrongStepIdSets` 暂定的是**原始步骤中可观察到的错误**。学生随后纠正某一步，并不意味着原始文本从未出错；但关于错误原因的假设必须随新证据调整。`requiresCounterevidenceCorrection` 仅4个反证目标案例为true，其余为null，避免把不适用项塞入指标分母。

`allowedCategories` 表示暂时允许考虑的粗类，不证明类别对应的心理成因已经确定。`null` 表示未设定或不适用，`[]` 表示此处不期待活跃错误类别；教师须独立判断其意义。证据不足不等于题目没有数学答案，例如d21参考最小值可以确定，但缺少学生本人过程，不能据答案反推掌握程度。

## 两位教师独立审核与仲裁

1. 负责人冻结并记录版本/hash，向A、B分别提供同一输入集与各自空白模板。隐藏另一位教师的结果、作者暂定sidecar、参考解文件及所有模型输出。教师先独立解题，检查题干充分性、课程范围、原步骤可读性、多解/无解/条件边界。
2. 教师独立填写 `expected`：可接受的原始错步集合、允许的粗类、信息不足/无错误/反证/答案泄漏的适用目标，以及解释。可接受多种错步定位时列出多个集合。明确无错误可用 `[[]]`；不适用用null。不得为填满表格给全部字段强行设true/false，也不得把过程差异直接当成错误。
3. 各自原标签分别保存到新的本地审核目录，禁止将一份标签复制署为两人。仓库模板继续保持空白；真实教师身份材料、同意书、联系方式不提交仓库。匿名reviewerId、时间和hash是流程声明，不验证现实身份，不是数字签名。
4. 对每个标签先构造 `conversationGoldReviewPayload(annotation)`，其内容为 `{caseId,inputHash,expected}`，再用 `hashValue` 生成labelHash。只签expected会丢失题目绑定，因此本批不接受这种做法。各教师必须签自己实际完成的标签；A/B原始完整标签与签收记录都要保留。
5. 两份标签完全一致时，最终 `review.status=AGREED`，两条独立reviewerId不同，且两人的labelHash均等于最终payload hash。有任何差异则保持DRAFT，保留分歧，由第三位教师独立仲裁，记录理由、时间及最终payload hash。仲裁人不能是A或B；最终为ADJUDICATED，A/B原hash不得覆盖成仲裁hash。
6. 只有实际完成上述审核后，才能将该标签改为 `TEACHER_REVIEWED`，并在新数据版本中更新对应case的审核状态与全套绑定。当前文件仍全部PROVISIONAL。输入或参考标准修改后须升版本、重新计算datasetHash/inputHash及相关签收；不得沿用失效签收。
7. 模型输出质量须另做双人盲审：教师阅读固定输入、完整会话与已审标签，隐藏供应商/模型名、费用/延迟及另一人的评分。七项0–2量表由会话评测流程提供，需绑定完整transcriptHash。不能仅凭输入标签、关键词命中或作者脚本自动填教育质量分。没有实质反证、追问或建议可审时，相应量表填null并说明原因。

本集的4条预设反证回答都是作者提供的数学解释；正式审阅须判断模型是否真的引用、理解并修正了先前归因。单纯收到一条正确回答不等于长期掌握，也不允许把“学生称自己写漏/录入错”升级为已经核实的原稿事实。

## 复现与实际证据

在仓库根目录执行，无需密钥，不调用任何模型：

```powershell
npx tsx scripts/eval/m7-dataset.ts
npx eslint scripts/eval/m7-dataset.ts
```

校验器检查严格schema、40条和七类型数量、来源/未审状态、逐例hash、标注步骤引用、双审空白性、24/16清单覆盖与题族隔离、重复输入hash/规范化题面、manifest文件字节hash，并执行40例共100项确定性数值断言。算术核验使用受限表达式解析器，无eval或任意代码执行。它验证数值参考与部分反例，不是通用数学证明器；缺图和拒答等教学含义仍依赖人工审阅。

修改数据须先复核与升版本，再显式执行 `npx tsx scripts/eval/m7-dataset.ts --refresh-manifest` 更新提交用manifest。普通校验不会更新manifest；任何绑定失配应报错，不能以重算hash来掩盖未复核的输入变化。每次成功校验均写入 `.local/m7-dataset-validation/<新UUID>/validation.json`，保留已有目录，不清空或覆盖历史输出。
