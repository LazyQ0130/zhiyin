# M6 真实模型受控测试

本轮真实 API 请求 **0 次、供应商费用 0 元**。当前未配置真实 Key、未获得单次调用授权；所有通过证据来自单测、Mock 或明确标记的合成上游。真实教育质量、OCR、供应商授权/地域、实际账单与延迟尚未验证。

## 官方协议核验（2026-10-23）

[模型页](https://help.aliyun.com/zh/model-studio/qwen3-8-flash) 明确 ID 为 `qwen3.8-flash`，支持图文与结构化输出，最大输入 991808 tokens。北京无折扣参考价格为输入 0.8、输出 2.7 元/百万 tokens；新加坡参考价不同，不能混用。

[Chat API 官方说明](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions) 支持 OpenAI 兼容 POST `/chat/completions`。当前实现用顶层 `enable_thinking:false`、`stream:false`、`response_format:{type:"json_object"}`；Prompt明确要求 JSON。JSON mode 只保证 JSON 格式，本地继续做 Zod 结构、状态、引用与逐字证据校验。未把 JSON mode 误称为服务端严格 Schema 保证。本轮用 `max_completion_tokens` 替换即将废弃的 `max_tokens`，只接收 `finish_reason=stop`。非成功 HTTP、超时、网络错误、无效 JSON/Schema 和截断均返回失败，不切换 Mock。

网关只允许官方 DashScope legacy 或列出的业务空间域名及固定 API 路径，拒绝非默认端口、认证信息、query/hash，禁用重定向。账号具体业务空间和地域授权仍须真实验证。文档提供的是协议依据，不能替代实际调用结果。

## 先完成零网络演练

```powershell
npm run eval:validate
npm run eval:demo
npm run eval:plan
```

`eval:demo` 是本地 Mock；`eval:plan` 仅保存 `NOT_RUN` 计划与 datasetHash/caseIds。结果在 `.local/m6-evaluation` 或 `.local/evaluations` 的新目录中，不进入 Git。模型仅接收 inputs 的 context，不接收 annotations 或教师评分。

`npm run eval:live` 缺少授权文件会以程序退出码 2 拒绝，networkRequests=0。旧 `npx tsx scripts/eval/live-smoke.ts` 已改为相同受控入口，不能仅靠环境变量绕过授权。npm/npx/PowerShell可能包装非零退出码；内部程序状态和结构化结果同时保留。

## 将来取得人工授权后

账户持有人必须明确确认模型、地域、数据范围、请求数和费用，配置服务端 `AI_MODE=live`、`ALIYUN_API_KEY`。不要将 Key 写入参数、报告、截图、fixtures或 Git。当前任务未提供上述授权，因此本轮不执行这些步骤。

把 `docs/evaluation/live-permit.example.json` 复制到 `.local/live-permit.json`，人工填写新的 UUID、审核人、UTC 起止时间、确切 datasetHash/caseIds和当前核对的地域/价格，并将 `approved` 改为 true。示例默认 false/占位时间，必定拒绝，程序不会自动生成获批授权。

授权最长24小时、最多3次请求，总预算不超过10元；本轮推荐一次一个样本。定价确认须在7天内，地域必须与endpoint对应，低于本次核验的无折扣价格会拒绝。`maxRequestBytes` 限制完整请求体，`maxCompletionTokens` 限128–2500，不启用思考、缓存优惠假设、自动重试或高价模型升级。网关单次失败立即停止该批次；未完成的已选案例由评分程序记为缺失失败，不能缩小分母。

每一次 fetch 前重新检查到期时间。非北京地域保守使用更高的输入1.094/输出3.427无折扣价下限，涵盖美国部署范围差异；本轮官方页面未提供明确价格的香港地域不允许真实runner调用，等待补充核验。

```powershell
npm run eval:live -- --permit .local/live-permit.json --case sign-error
```

授权用独占文件 `wx` 在任何网络请求前消费，禁止同一 UUID 再用。网络中断或进程中止也不释放授权；恢复须重新取得授权并生成新 UUID。该机制依赖受信任本地操作者和磁盘，不是远程审批签名系统，也不能抵御有本机写权限者篡改程序或账本。

## 预算与结果口径

先按官方模型的整个输入上限（991808 tokens）与配置输出上限加10-token误差预留最坏估计，再检查每次真实 fetch 的endpoint、参数、次数和字节。北京2500输出上限时每次保守预留约0.8002234元，而实际请求通常远小于此值。这不是预计一定消费的金额。价格变化或供应商异常仍需控制台额度和账单监督，本地预留不能作为供应商硬性扣费上限保证。

`run.json` 保存每个实际完成/失败请求的输出或安全错误码、tokens、延迟与估算；`billing.json` 分开记录网络尝试、预留、估算与 `actualInvoiceCostCny:null`。未知 usage/费用保持 null，失败不等于免费。逐次落盘；如果进程在请求后、写盘前崩溃，消费凭据和已预留额度还在，须手工核对供应商账单，不能重放冒充未调用。零网络拒绝单独保存 `blocked.json`，不伪造 LIVE 成功。

将实际 `run.json` 与教师侧标注按 `npm run eval:score -- <inputs> <run> [annotations] [output-reviews]` 对比。单次 API 合法响应仅能证明协议兼容；教师盲审、样本量、分层表现、失败率与覆盖率通过后，才讨论下一轮成年封闭试测。标注流程见 [评测与教师标注规范](M6-评测与教师标注规范.md)。
