# 受控多轮执行说明

本入口仅用于管理员本地评测，没有网页入口。当前真实教师审核及新调用授权均未完成，因此不能执行真实请求。M9 原 `M9.PLAN.1` 是历史准备材料，保留原件及当时的未实现状态；它不是本入口可接受的许可，M7 已消费许可也不可复用。

## 执行前人工条件

1. 真实 A/B 教师独立审核，收到原件、人工核实来源，保留分歧；必要时独立第三人仲裁。复用 [教师说明](M9-教师试标说明.md) 和 M8 `attach-source / validate-audit / compare / adjudicate`。生成表、导入成功或自报身份均不等于 `HUMAN_VERIFIED`。
2. 保留原 PROVISIONAL 父集及试标子集，另建经过审核的 DEV 数据版本。不能只改状态字段：执行门禁重新构造题目、步骤、回答投影，与两份教师原始审核包及实际签署文件字节核对。子集审核不能冒用父集 hash；不使用 BLIND。
3. 获得针对具体新数据集、模型、样本、回合、请求数和预算的**新明确授权**。由管理员按 [许可 Schema](../src/evaluation/m9-multi-permit.ts) 填写 `M9.MULTI.1`，记录真实批准人及时间，不由程序制造批准。许可最长24小时；授权 ID 一次消费，原共享账本独占写入。
4. 人工重查北京区官方价格（最多7日前），填写保守价格，不假定折扣；预算须覆盖许可全部请求的模型输入上限及输出上限预留。Token 换算为估算费用，不能视为实际账单。未收到用量时费用为未知，保留预留并停止。

## 配置及命令

配置、许可、教师决定和真实签署原件均放在 Git 忽略的 `.local/` 内；路径相对于配置文件。`teacherGoldDecisionsFile` 是真实 M8 `INPUT_GOLD` 决定对象的 JSON 数组，不是作者标签；`signedSourceFiles` 必须包括绑定的 A/B 原始字节及存在仲裁时的第三人原件。

```json
{
  "schemaVersion": "M9.MULTI.CONFIG.1",
  "datasetFile": "reviewed-dev.inputs.json",
  "permitFile": "permit.json",
  "teacherGoldDecisionsFile": "human-verified-decisions.json",
  "signedSourceFiles": ["teacher-a-original", "teacher-b-original"]
}
```

```powershell
# 只检查，不读 Key、不连接供应商、不消费许可
npm run eval:m9-multi -- check .local/reviewed-run/config.json
# 以下仅在上述人工条件和新授权实际满足后执行：首次只发1轮
npm run eval:m9-multi -- start .local/reviewed-run/config.json --execute
# 状态读取不发请求，到期许可仍可查看；RUN_ID 替换为实际值
npm run eval:m9-multi -- status .local/reviewed-run/config.json RUN_ID
# 教师/操作员看过当前AI追问，确认脚本回答仍符合追问后才填写批准
npm run eval:m9-multi -- resume .local/reviewed-run/config.json RUN_ID .local/reviewed-run/reply-approval.json --execute
```

等待续轮时生成 `approved:false`、批准人空白、时间 null 的草稿，包含上一轮检查点 hash、防护后输出 hash、确切脚本回答及其 hash。操作员必须阅读原始/防护输出和脚本回答，只有确实对齐时才填真实批准人、当前 ISO 时间及 `approved:true`。不对齐就停止，不擅改脚本、不自动续发；修改脚本须重新审核、版本绑定及授权。跨案例也需单独确认。草稿不是批准，禁止循环自动填写或无条件确认。

许可严格限定北京 `qwen3.8-flash`、当前 Prompt 和五个诊断规则文件 hash，1–3个已审核DEV案例、每例1–3轮、总计最多9请求及许可内预算（上限¥8）。实际批准可以更小；不提供自动重试，并发为1。请求发送前重新核对到期时间、模型、完整上下文、确切请求体、字节、回合、计数和预留费用。

## 记录与失败处理

`.local/m9-live/RUN_ID/` 保存每轮原始诊断文本、防护后输出、各自 hash、上下文、批准记录、Token、延迟、供应商证据和费用估算。HTTP错误没有诊断文本时明确缺失；供应商证据有大小上限及截断标记。Key 脱敏；发生脱敏、截断、非法输出、超时、连接失败、未知用量或上限触发均停止，不回退Mock。实际账单保持 null，待人工核账。

请求前将不可覆盖的 claim 和费用预留落盘，结果写追加检查点。崩溃留下 claim 时视为发送情况未知，禁止续跑或删除锁后重试；先人工查供应商用量，若需再次测试必须获得新授权。历史原件、账本和失败目录均保留，不提交 Git。只支持受邀成年人本地测试，不改变应用 Mock 模式、导航、数据库或注册约束。

`tests/unit/m9-multi-*.test.ts` 中的教师、许可及模型响应仅为 `UNIT_FIXTURE` 合成故障测试，不能导入为真实审核或教育质量结果。
