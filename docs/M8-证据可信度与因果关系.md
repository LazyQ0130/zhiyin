# M8 证据可信度与因果关系边界

本文件描述服务器约束和离线工程测试，不构成教师质量结论。实现不会调用真实供应商、补造学生步骤、自动确认心理原因或长期掌握。

`schemaVersion: "1.0"` 和原有五种 finding status 保持兼容；新增可选 `finding.trust`。旧模型输出仍可解析，运行时 `validateDiagnosisTurn` 为所有发现补齐可信度。历史没有该元数据的行只能使用保守的 `legacyFindingTrust()`，不可按旧 `SUPPORTED` 或 `VERIFIED` 追认原因。

| 字段 | 含义 |
| --- | --- |
| `kind` | `OBSERVATION` 可定位的本次表现；`HYPOTHESIS` 原因候选；`VERIFIED` 受限规则核验的运算事实；`INCONCLUSIVE` 信息不足 |
| `uncertainties` | 显式证据限制，包含心理原因、独立性、关系未知等尚未解决事项 |
| `verification.state` | 本轮未检查、支持、削弱、反证、运算事实已验证或无法判断 |
| `verification.basis/evidence` | 学生回答或确定性规则的实际作用域引用，不允许引用其他会话 |
| `rootCause.role` | `INITIAL` 初始错误位置；`PROPAGATED` 前错传播；`INDEPENDENT` 另一个局部错误；`UNKNOWN` 缺少关系证据 |
| `candidateRootId` | 作用域内 findingKey，共同根候选使用同一个 ID；这是错误位置候选，不是已验证的心理原因 |
| `relatedFindingKeys/upstreamStepIds` | 上游发现和步骤引用；缺失 ID、跨范围引用、自引用与有向环会被拒绝 |

## 服务端执行规则

`src/server/ai/evidence-trust.ts` 的 `normalizeEvidenceTrust(turn, context)` 根据当前步骤、回答和历史发现归一。输入与结果不依赖外部模型或网络。重复运行的结果必须相同，避免 Mock、Aliyun 和服务层多次校验时升级确定程度。

单步表现、学生自述和计算工具均不能验证“误记公式”“概念不理解”“粗心”等心理原因。无后续证据的原因 `SUPPORTED/VERIFIED` 降为待验证假设；确定断言替换为中性描述，同时修正面向学生的确认文案。不是只改状态或在断言前加一个不确定标签。原始录制响应和历史字符串应继续作为私有原始证据保存，不因新的安全呈现改写历史快照。

后续独立局部核算与负号规则一致时，可对该规则理解假设构成反证；前一个提问必须保存服务器 `CLEAR` 且有效等级 0 的帮助记录。未知帮助或已暴露提示只削弱该假设，保留 `UNRESOLVED/WEAKENED`；答对不能确认另一种心理原因。再次算错最多支持原因候选。未知语义回答不会仅凭模型把回复 ID 塞入数组就自动变成原因验证。

当前未重新提供证据的历史原因保留为待确认，不能通过在新输出中省略它来维持数据库中旧确定程度。超过八条容量时拒绝整轮，防止静默丢掉历史原因。只有题干/工具、缺少学生过程时使用信息不足描述；受限局部核算自洽时，不凭模型断言制造该步错误。

工具仅能验证运算事实。即使匹配规则，归一也不会自动把 `HYPOTHESIS/SUPPORTED` 升级为 `VERIFIED`；一个已声明 VERIFIED 的运算观察还须满足后续回合、真实工具引用和受限规则的错误位置证据。首轮或缺少工具的 VERIFIED 继续沿用既有拒绝约束。

## 数学关系检查范围

`src/server/domain/math-evidence.ts` 不运行学生代码。受限解析器只接受不超过 240 字符、100 词元、12 层嵌套的数字、已定义中间量、括号、四则运算、平方根和有限整数指数；拒绝函数调用、任意标识符、除零和超过数值边界的运算。

检查支持两类证据：显式命名中间量（如 `u=2+3=6`、`v=u*2=12`）的错误传播；唯一、有限整数系数二次方程中，错误判别式到求根公式代入的自洽传播。系数和数值来自输入，不绑定 M7 单题、步骤序号、发现键或某个固定错误数值。后步另外出现算术不成立时保留独立错误候选，不能为了减少根数而全部合并。表达式或关系不在受限解析范围内时保留 UNKNOWN，不能推断“未识别即独立”。这不是通用代数证明器，也不能代替语文语义、开放证明或教师判断。

`summarizeRootCauses(findings)` 按共享候选 ID 汇总错误位置组，单列前错传播和未知关系；汇总数字不能称为心理错因识别正确率。

## 验证

`tests/unit/m8-evidence-trust.test.ts` 覆盖：旧 1.0 兼容；步骤观察与心理假设分离；工具不能验证记忆；不自动升级；遗漏历史原因；缺过程及正确步骤；无关回答；未知/有提示/明确无帮助时的反证差异；二次错误支持假设；重复归一幂等；两个二次方程系数族；通用中间量传播；多个独立候选；UNKNOWN 不强连；跨范围引用、循环、重复键；可信度证据摘录；解析资源界限。既有反证测试增加保存可审阅无帮助问题，避免用只有一条学生回答的缺失历史冒充独立验证。
