# M8 服务端辅助内容复核与练习独立性

日期：2026-10-23。此机制是本地、可审计的保守内容检查，不调用模型或外部服务。它提供已识别帮助的强度下限，不能完整判断任意自然语言是否泄露答案，也不代表教育效果通过。

## 输入与输出

`src/server/domain/assistance-review.ts` 导出：

```ts
reviewAssistance({
  studentFacingText,
  followUpQuestion?,
  findings?,            // 检查向学生展示的 statement，不把引用摘录当作新指导
  declaredHintLevel,
  requestedAction?,
  subject?,
  questionText?,
})
```

输出包含 `status`、`declaredLevel`、`minimumLevel`、`effectiveLevel`、`reasons`、`reviewRequired` 和固定来源 `SERVER_CONTENT_REVIEW_V1`。均可 JSON 序列化；原因采用稳定代码，不复制学生原文或真实响应原文。

| 级别 | 含义 | 工程识别例 |
|---|---|---|
| 0 | 未提供帮助 | 仅对整段内容匹配封闭的无指导思路追问模板，例如“你当时是怎么想的？” |
| 1 | 方向 | 指向检查某一步、符号或方法 |
| 2 | 关键知识 | 给出公式、规则、语义边界，例如判别式公式或“至少包含等于” |
| 3 | 答案或局部结果 | 数值答案、已算出的中间结果、具体选项、带答案的反问或语言形式 |

检查覆盖部分中文、英文、Unicode/LaTeX 公式及间接答案表述，并同时检查追问与 finding 的正文。模型自报零不覆盖内容检测结果；有效级别取模型声明与已识别内容下限中的较高值。用户请求提示本身也是帮助事件，最低记 1 级，不能因文本未识别而恢复独立性。

`CLEAR` 只表示匹配封闭的已知无帮助范围。自由生成文本未命中任何规则时返回 `UNCERTAIN`，`minimumLevel=null`；模型也自报零时 `effectiveLevel=null`。如果模型自报非零但无法判断实际内容，仍保留 `UNCERTAIN` 与待复核。`DETECTED` 表示已识别至少某一级帮助，不能据此排除更强、未识别的帮助。检测等级高于声明等级时标出不一致并要求复核。

`subject` 与 `questionText` 保留上下文接口；当前规则不据此执行通用学科推理、验证答案或推断心理原因。未覆盖领域、复杂隐喻、上下文暗示、否定句和语义歧义仍可能误报或漏报；未命中的默认未知可以阻止其被错误计作独立证据，但不能替代人工复核。

## 记录范围与持久化

诊断每轮的内容复核存入 `DiagnosisMessage.assistance`，与兼容用的模型 `hintLevel` 分开。它描述该消息及其展示的 finding 内容，不保证学生此前从未得到外部帮助。旧消息无该记录时，在界面显示帮助内容待复核。

规则题创建时才使用 `knownNoAssistance()` 写入 `PracticeItem.assistance`。该记录只说明这道新题尚未展示帮助。原诊断题即使给过提示或答案，也不自动污染不同的新规则题；复测的新题重新建立自己的帮助记录。通用的诊断 `CLEAR0` 记录不能用来证明某道练习题未得到帮助。

实际请求练习提示在同一事务与题目锁内写入：

- `hintUsed=true`；
- `hintUsedAt` 首次时间，重复请求保留；
- 对实际提示文本的内容复核；同题多次事件合并时保留较高帮助级别与既有不确定性。

提交时 `recordedPracticeAssistance()` 只读服务端题目记录。`hintUsed`、`hintUsedAt`、已展示解法状态或非零内容复核任一存在，都不能恢复独立；答案或结果暴露记为 `SOLUTION_VIEWED`，其他已知帮助记为 `HINTED`。缺少记录或记录无法解析时为 `UNKNOWN`。客户端提交接口仍只接受答案文本，不接受 `hintUsed=false`、独立性或帮助级别覆盖。

`PracticeSubmission.verifierDetails` 持久化：

```ts
{
  schemaVersion: '1.0',
  verifiedBy: 'RULE' | 'PENDING',
  independence: 'INDEPENDENT' | 'ASSISTED' | 'UNKNOWN',
  independenceReasons: string[],
  assistanceReview: AssistanceReview | null,
}
```

正确性仍独立计算。数值可确定为正确但帮助来源未知时，结果保留 `CORRECT`，独立性是 `UNKNOWN`，`masteryState=NOT_ENOUGH_EVIDENCE`，练习组待复核。旧 submission 不重写；读取旧记录时不得以缺失字段推定独立。已知没有展示帮助的新规则题答对仍可成为本次独立验证通过，不推断长期掌握。

## 验证

`tests/unit/assistance-review.test.ts` 使用原创合成文本验证中英文方向、公式、关键知识、数值与间接答案、声明零与实际帮助不一致、未知回退、题目范围、旧记录、提示时间戳、解法展示与同题帮助升级。原有数学规则与练习单测继续验证未辅助新题可通过。

M7 的真实响应证据继续仅在原 Git 忽略目录只读保留；本模块测试不复制真实原始日志、请求或密钥，不追加真实调用。
