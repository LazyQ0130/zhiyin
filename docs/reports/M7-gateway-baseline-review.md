## 官方协议复核

仅使用阿里云官方资料。模型 ID 为 `qwen3.8-flash`，非思考模式最大输入 991808 tokens；北京未折扣输入/输出为每百万 0.8/2.7 元，新加坡为 1.094/3.427 元。香港价格未列入本次可核验列表，继续拒绝；其他非北京地域使用更高保守下限。[模型与价格](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)

官方支持兼容接口 POST `/compatible-mode/v1/chat/completions`；HTTP 请求将 `enable_thinking:false` 放在顶层。`max_completion_tokens` 限制完整输出，实际可能有最多 10-token 误差；`json_object` 保证 JSON 格式，须提示 JSON，结构仍由本地校验。实现与这些协议相符。[Chat API](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)

## 网关审查与修复

- 请求固定关闭流式和思考，默认输出限额 2500；仅官方 HTTPS 域名、固定路径、无 query/hash/非默认端口/URL 凭据，重定向直接失败。
- JSON 解析后继续严格 Zod 结构与动作约束，逐条校验步骤/回复/题干/工具的作用域和原文摘录；仅 `finish_reason=stop` 可继续校验。不合法输出失败，无 Mock 回退。
- 修复跨重试用量：任一尝试缺失某项 usage，该项汇总为 null；输入和输出分别计算。已知部分不能冒充完整计费量，失败也不等于免费。
- 新增只读 `AliyunGateway.lastResponseEvidence`，每次调用清空历史；返回副本。每个尝试保留 HTTP 状态、供应商请求 ID、finish reason、响应 SHA-256、脱敏响应片段、截断标志及安全错误码，无 console 输出。
- 成功和非 2xx 响应均流式读取，超过 100000 字节即取消。响应片段脱敏后最多 16384 UTF-8 字节；配置的 Key、通用及带点 workspace Key 形态均替换，元数据也脱敏限长。没有响应时不伪造响应体、状态或哈希。哈希基于读取的原始字节；读取截断时只覆盖已捕获部分，截断标志明确。
- 证据仅供服务端受控 runner 写入被忽略的本地目录，不进入客户端 DTO 或提交。响应片段即使脱敏仍可能含输入回显，应继续作为本地私有运行数据处理。

`tests/unit/m7-gateway-evidence.test.ts` 使用假 fetch 验证错误响应、元数据与 Key 脱敏、字节限额/取消、缺失及部分 usage、截断 finish reason、网络失败和调用间隔离；未访问供应商。

## 授权边界

既有 M6 batch 协议保留最多三次的能力；M7 新增独立 single protocol 入口，不把批次许可当成单次许可。新 guard 要求固定协议数据集和样本、精确 dataset hash、人工 approved 许可、maxRequests 恰为 1，再沿用限时、预算、地域、定价和独占消费控制。单次网关 maxRetries 为 0；每次 fetch 重新检查到期、端点、参数、字节及次数，任何失败停止。

`tests/unit/m7-authorization.test.ts` 仅调用纯拒绝函数：缺失/未批准许可不能被 Key 或 live 环境替代；选择漂移、hash 漂移、maxRequests=2 即使只选一个样本仍拒绝。未调用 --execute，不生成许可文件或真实消费账本。

本地 JSON 许可与 wx 账本依赖受信任的本地操作者和磁盘，不等同于远程审批签名或供应商硬预算。真实授权、账户地域、实际响应与账单仍须由账户持有人另行确认，当前全部未运行。

## 会话评分门禁复核

新会话评分区分结构、引用作用域、上下文连续性与人工教育质量。后者须真实 LIVE_API、FINAL_EVALUATION、BLIND 样本及审核金标；Mock、工程候选标签与盲集审计不能成为正式质量结论。教师金标绑定输入 hash，输出审阅绑定完整 transcript hash；失败在适用目标计 0，缺标签或未签收评分保持 null，并报告分母及覆盖率。

这只是可计算质量指标的资格门禁，尚无教育负责人冻结的准入阈值。formalQuality 有数值不代表获准试测；真实教师审核、质量阈值及供应商账单仍属未完成事项。
